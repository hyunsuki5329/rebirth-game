# Bow pixel art v1

Built-in image_gen generated `Assets/_Game/Art/Weapons/Bow.png`. The PNG has a transparent alpha channel (corner alpha 0), 1024 × 1536 source pixels. Unity imports it as a Point-filtered, uncompressed sprite without mipmaps, with a 512 maximum texture size. The player displays this sprite only while Bow is selected and rotates it toward aim.

The small arrow sprite is original code-generated pixel art in BowBuilder, saved as `Assets/_Game/Art/Weapons/Arrow.png`.

## Image generation prompt
Create ONE isolated original fantasy recurve BOW game sprite for the same teal/copper/steel pixel-art explorer weapon set shown previously. Transparent RGBA background, NO text, NO sheet, NO shadow, NO glow backdrop, NO character, NO arrow, no duplicates. Single bow centered with generous transparent margin. True crisp low-resolution pixel art with chunky square pixels and dark outline, limited 8-color palette. Dark walnut wood limbs with warm copper caps and a teal cloth-wrapped central grip, ivory thin taut bowstring. Bow held vertically, tips on the right and curved grip on the left, so it fires towards the RIGHT (+X); the silhouette resembles a left parenthesis with a straight string connecting the two rightmost tips. Orthographic 2D sprite, no perspective or dramatic lighting. Clean symmetrical upper/lower recurve, readable at about 32x64 logical pixels when reduced. Match the earlier weapon set's simple practical aesthetic. Render as a polished standalone sprite asset, no antialias blur.
