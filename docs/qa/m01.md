# M1 — Player Controller

## Implemented
- Fixed Player action map: WASD movement, Left Shift hold sprint, Space dash, Mouse position aim, left button attack request. Existing UI map retained.
- PlayerInputReader clones the actions and releases states on disable, blocking and focus loss.
- PlayerMovement/PlayerSprint/PlayerDash/PlayerAim are separate. PlayerMotor2D alone applies player body velocity.
- PlayerStats asset: move 5, sprint 1.5, dash distance 3 over 0.16 seconds, cooldown 0.8 seconds after dash end.
- Player prefab and PlayerArena scene with walls, camera follow and aim marker.

## Automated validation

- PlayMode 6/6 passed: M0 gravity/collision; virtual WASD/Left Shift input; UI block and focus loss; sprint/dash speed/distance/cooldown/wall; idle mouse aim dash and left-click input; equal-time axis/diagonal travel; walking/sprinting dash distance comparison.
