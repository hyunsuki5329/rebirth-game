# M12 — Vertical Slice integration

## Implementation
GameBootstrap owns GamePause. The on-screen Pause button freezes scaled time and audio, clears/blocks PlayerInputReader and rejects new attack/Dash requests. Resume restores the previous time/audio state. Menu transitions and controller disable release an owned pause. The pause overlay offers Resume and the existing master-volume controls. Hub can return to MainMenu; RunFlow refuses menu transitions during a run, preventing settlement bypass.

The dungeon HUD includes HP, raw/applied Gold, Momentum, permanent multiplier, Threat, Combo/evolution progress, Dash cooldown, controls and Boss HP/phase. Input bindings are unchanged. No new content, packages or performance framework were introduced.
